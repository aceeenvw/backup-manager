# ⊹ BACKUP MANAGER ⊹

Choose what to save from SillyTavern and download it in one ZIP.

- **Chat and library backups:** Collect character cards, solo and group chats, lorebooks, backgrounds, themes, personas, Chat Completion presets, global regex scripts, or extension links.
- **Character selection:** Choose cards and solo chats independently. Search by name or `#tag`, then choose **Use matches**. With a solo chat open, **Current** selects its character; **Current chat** selects just that saved conversation.
- **More file tools:** Select or drop PNG and JSON files on **Import cards** for bulk import. Download the open solo or group chat as JSONL, or use **Save to folder** in supported browsers to write a backup without packing a ZIP.
- **Images from chats:** Use the folder icon to include all gallery folders or select individual ones.
- **MemoryBooks:** Save side prompts and their sets in `memorybooks/stmb-side-prompts.json` for [MemoryBooks’](https://github.com/aikohanasaki/SillyTavern-MemoryBooks.git) by aikohanasaki side-prompt importer. `preferences.json` is a readable reference for manually restoring core settings. Connection profiles and API-key fields are excluded.

In **Extensions → Install Extension**, paste `https://github.com/aceeenvw/backup-manager`. Open **Extensions → ⊹ BACKUP MANAGER ⊹**, select categories, and choose **Create backup ZIP**.
